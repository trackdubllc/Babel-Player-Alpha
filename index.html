Desktop-first · local-first · segment-based

Babel Player is a Windows dubbing workstation for local media. Load a file, generate timed transcripts, translate dialogue, assign voices to speakers, preview changes in context, and regenerate only the lines you changed.

Workflow

Babel Player is not a one-shot subtitle tool. It is built around a staged dubbing loop where each line of dialogue can be edited, regenerated, and previewed in place.

  1. Open local video or audio
  2. Transcribe timed dialogue
  3. Identify speakers and assign voices
  4. Translate segment by segment
  5. Generate TTS per line or per speaker
  6. Preview against the original media
  7. Refine only what changed

Current shape of the product

Windows-first, actively evolving, local-first by design, with optional bring-your-own-key cloud providers for stages where you want them.

Why Babel Player

Local-first workflow

Bring in local media, keep artifacts on disk, and reopen work later without starting from zero.

Segment-level regeneration

Edit one translated line or reassign one speaker voice without blowing away the whole pipeline.

Explicit compute paths

Each stage exposes CPU, GPU, or cloud routes clearly so the app’s state matches reality.

Managed local runtime

The app bootstraps its own local inference environment instead of asking users to manually set up Python.

Preview in context

Work against the real media instead of editing blind text and only hearing the result at the very end.

Optional cloud, not mandatory cloud

Cloud providers are opt-in and BYOK. The default posture is local, inspectable, and under your control.

Requirements
OS Windows 10 or 11
Architecture x64 and ARM64
GPU (optional) NVIDIA CUDA recommended for heavier local GPU paths
VRAM Around 6 GB minimum for many GPU routes, more for larger models and cloning-oriented workflows
Release builds Self-contained, no separate .NET runtime install
Source builds .NET 10 SDK

First-time local inference may download a managed runtime and model assets, depending on which path you choose.

Privacy and licensing

Processing stays on your machine unless you deliberately route a stage through a cloud provider and supply your own key. There are no accounts required to use the app itself.

Model and voice licenses vary. If you plan to use Babel Player in commercial workflows, review the repository’s license notes and third-party model restrictions before relying on any specific provider or bundled path.
